# 🤖 Timberland HR-бот для Telegram

Telegram-бот для автоматизации взаимодействия сотрудников с HR-отделом. Позволяет задавать вопросы, отправлять обращения, скачивать памятки и регламенты, а также вести чат с HR в реальном времени.

---

## 📋 Функционал

### 👤 Для сотрудников
- **Регистрация** — при первом запуске сотрудник заполняет анкету (ФИО, подразделение, должность, дата приёма)
- **Создание обращения** — кнопка "❓ Задать вопрос в отдел персонала"
- **Чат с HR** — общение в реальном времени после того, как HR взял обращение в работу
- **История диалога** — просмотр переписки с HR
- **Памятка сотрудника** — скачивание PDF-памятки
- **Общая информация** — просмотр информации о компании (PDF)
- **Регламенты компании** — скачивание регламентов (PDF)
- **Полезные контакты** — контакты всех отделов
- **Сброс данных** — команда `/reset` полностью удаляет данные сотрудника

### 👨‍💼 Для HR (отдел персонала)
- **Просмотр обращений** — список всех активных вопросов
- **Открытие чата** — начало диалога с сотрудником
- **Уведомления** — автоматическое уведомление сотрудника о начале/завершении диалога
- **Быстрые ответы** — кнопки "Уточняю информацию" и "Вопрос решен"
- **История диалога** — просмотр полной переписки
- **Информация о сотруднике** — просмотр данных сотрудника (ФИО, отдел, должность, дата приёма)
- **Удобное меню** — кнопка "⛔ Завершить диалог" всегда под рукой

### 📄 Документы и файлы
- **Общая информация о компании** — PDF (кнопка "ℹ️ О нас")
- **Корпоративная культура** — PDF (кнопка "📂 Регламенты компании")
- **Организационная структура** — JPG (кнопка "📞 Полезные контакты")
- **Памятка сотрудника** — PDF (кнопка "📋 Памятка сотрудника")

## 🚀 Быстрый старт

### 1. Клонировать репозиторий
```bash
git clone https://github.com/ваш-username/timberland-bot.git
cd timberland-bot
```

### 2. Установить зависимости
```bash
pip install -r requirements.txt
```

### 3. Настройка конфигурации
Создайте файл `config.py`:

```python
TOKEN = "ВАШ_ТОКЕН_ОТ_BOT_FATHER"
HR_CHAT_ID = 123456789  # ID Telegram HR-сотрудника
```

### 4. Создать папку для файлов
Создайте папку `files/` и поместите туда:
```
Общая_информация.pdf
Корпоративная_культура.pdf
Оргструктура.jpg
Памятка_сотрудника.pdf
```

### 5. Запустить бота
```bash
python bot.py
```

## 🛠️ Технологии

- **Python 3.10+** — язык программирования
- **Aiogram 3.x** — фреймворк для Telegram ботов
- **SQLite** — база данных
- **FSM (Finite State Machine)** — управление состояниями регистрации

## 🚨 Возможные проблемы и решения

### Ошибка `TelegramConflictError`
**Причина:** Бот уже запущен в другом процессе.
**Решение:**
```bash
# Найти и убить процессы
taskkill /F /IM pythonw.exe
# Или перезагрузить компьютер
```

### Ошибка `no such column: hire_date`
**Причина:** Старая версия базы данных.
**Решение:** Удалить `bot_database.db` и перезапустить бота.

### Памятка не отправляется
**Причина:** Файл отсутствует или назван неправильно.
**Решение:** Проверьте папку `files/` и название файла `Памятка_сотрудника.pdf`.

### Кнопки не работают
**Причина:** Конфликт обработчиков.
**Решение:** Убедитесь, что в `hr_contact.py` нет обработчика для `"📋 Памятка сотрудника"` (он должен быть только в `memo.py`).
